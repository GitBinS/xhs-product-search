# 小红书商品搜索

把小红书**商品页 / 店铺页**采成结构化 JSON —— **桌面版与手机版 Obsidian 都能用**。

English intro in [README.md](README.md).

## 能采什么

**商品链接**（或分享文案 / 商品 ID）→ 归一化后的商品记录：

- 标题、售价、到手价、发货地、运费、发货时效
- 店铺名、店铺评分、店铺总销量、粉丝数、店铺链接
- 上架日期 / 上架天数（页面给得了才给，不给就留空）
- SKU 数、选中 SKU、商品角标、已售

**店铺链接** → 店铺信息 + 首页可见商品列表（店铺名、总销量、粉丝数、好评率、发货时效；每个商品含标题、价格、已售、上架日期/天数、角标）。

已售数字按页面原样保留：若页面只写「已售1.5万+」（下界）或只有当前 SKU 的量，数据里会带原文与口径标记，不冒充精确值。

**既可独立使用**（侧边栏图标或命令面板），也暴露 `checkDeps()` / `collect()` / `mode()` / `setMode()` 四个接口，供其他插件当数据后端调用（作者的带货工作台就是这么接的）。

## 保存为 Markdown 笔记

独立使用时（没装工作台），采集完点 **「保存为 Markdown 笔记」**：

- 数据写进笔记的 **frontmatter（属性区）** —— Obsidian 打开笔记直接可见，也能被属性检索；
- 正文只放：标题、商品链接、一张 **「每日跟踪（变动）」** 表（日期 / 商品销量）；
- **同一个商品再次采集 → 更新原来那篇笔记**（刷新属性 + 在每日跟踪表里改当天那行、隔天追加新行），不会多出一份重复文档；
- 保存目录可在设置里改（默认 `小红书商品采集`）。

## 工作原理

- 采集引擎**内置于插件**，用 Obsidian 官方跨平台网络接口 `requestUrl` 直连两个**公开**接口：
  - 商品详情：`mall.xiaohongshu.com/api/store/jpd/edith/detail/h5/toc`
  - 店铺首页：`www.xiaohongshu.com/shop/<sellerId>`（SSR，HTML 内嵌商品 JSON）
- **不需要 Python、不需要任何外部脚本、不需要 `pip install`**；**无登录态、无 Cookie、不碰任何账号数据**。
- 只有你**主动发起采集时**才会向 `xiaohongshu.com` 发请求，请求从你本机 / 本机设备发出。
- 采集结果只回到 Obsidian 里；插件无遥测、不写别处。

## 环境要求

- Obsidian 1.4.0+ —— 桌面版（Windows / macOS / Linux）**或移动版（iOS / Android）**
- 没有别的要求：**不需要 Python**、不需要 Node、不需要任何外部工具。

## 用法

1. 安装并启用插件。
2. 点侧边栏购物袋图标（或命令面板跑「采集一个商品」）。
3. 粘贴商品链接 / 分享文案 / 商品 ID（粘**店铺主页链接**则采店铺）。
4. 弹窗显示采集结果。
5. 点 **「保存为 Markdown 笔记」** 写入库内（目录见设置），或「复制为 JSON」。

**独立使用 vs 接工作台**：不接工作台时用「保存为 Markdown 笔记」落到库内（和「爆款笔记采集」插件一个思路）；接了带货工作台时，**写哪张多维表格由工作台的确认弹窗决定**（这里不重复管）。

命令：

- **采集一个商品（链接或商品 ID）**
- **采集器自检** —— 检查内置引擎是否就绪

> 分享短链（`xhslink.com`）在**桌面版**会自动展开；**移动版**请改用完整商品链接，或直接粘商品 ID。

## 已知边界（如实留空，不猜）

- 只在 App 端有的字段（如**开店天数**）网页采不到 → 留空，需手填。
- 店铺采集只拿**店铺首页可见**的商品，不是全店清单。
- 只支持公开页面；本插件没有任何登录能力。
- 已售数字按页面原文呈现（带原文与口径标记）。
